## Hand-step buttons

| # | Need | Today | Done when |
|---|---|---|---|
| E1 (B1, B4; the "no It failed" way of B3) | A step can hide any of its 3 buttons (Done, It failed, Skip) | A step can only rename them (`DoneText`, `NoText`, `SkipText`); `NoText` also changes the result to "Skipped by you" | A manifest field hides a button; a test shows a card with 1 and with 2 buttons |
| E2 (B2) | A step with only questions shows its first question at once | Done, It failed and Skip come first; questions only after Done | A manifest field (or: no guide lines and 1+ answers) goes straight to the questions; the result rule for such a step (for example, when an answer reports an error) is open: agree it with the PFM first |
| E3 | A question can depend on an earlier answer (show question 2 only if question 1 = "Inbox" or "Junk Email") | All questions always show after Done | A manifest field on a question names the earlier key and the answers that show it |

## Look (the PFM's notes L1-L8)

| # | Need | Done when |
|---|---|---|
| L1 | A fixed card frame: a minimum and a maximum height; the text scrolls inside; "Step x of x" in a fixed header row | The header row does not move between 2 steps of different length (measured on the Windows runner at 100 % and 150 %) |
| L2 | The app name sits close under "RADE", with a thin divider line as wide as the word "RADE" | Gap and line width measured in the Windows layout test, against target values the RADE session proposes and the PFM approves |
| L3 | The "Your answer" label sits above its box, and the box is the full card width | Windows layout test: label bottom above box top; box width = card text width |
| L4 | An optional last card in every round: "Anything else about this round or the app?"; the text goes into the report under its own line | The report file holds the text; empty is allowed |
| L5 | 2 fixed state texts: "Your turn." when the person acts; "RADE is working..." when RADE acts (replaces "RADE is waiting for you") | Text test |
| L6 | A first-run tour of 4-5 cards (what a round is, your turn and RADE's turn, what Done, It failed and Skip mean, where the results go); shown once and again from a Help button | Shown on first run only; Help opens it |
| L7 | A live "now doing" line under the bar: the current item of a script step as a plain sentence | The line changes while a script step runs (confidence medium that the engine can read the lines live: check this first) |
| L8 | After L1: each step stays on screen for a short minimum (about 0.5 s), or a run of fast steps shows as 1 line ("Checked 6 items") | No layout shift between steps in a recorded run |
