90161Z T21 PROBE APP r1 - code to copy (plain text, open in Notepad)

WHAT IT IS FOR
  The R26 probe test screen: a plain test screen, not a design screen.
  The RADE window's step text is the guide. This file is only the code to copy.

WHAT IT CHANGES
  One canvas app "90161Z T21 Probe r1" in Power Apps (you make it blank, then
  paste into it), and rows in the list "90161Z Probe". Nothing else.

BEFORE YOU START (the RADE window step text tells you how)
  - Make a blank canvas app named 90161Z T21 Probe r1. Add these data sources:
    the list "90161Z Probe", the library "90161Z Probe Files", the connector
    Office 365 Users, and the flow "90161Z T21 Probe App r1".
  - Studio may show a data source or the flow under another name. If a formula
    shows an error mark, select the name Studio offers and use it in place of
    the name in this file. The flow is written here as '90161ZT21ProbeAppr1'.
  - Sample text in this file says FAKE. Use no real names or addresses.

TWO WAYS FOR EACH BLOCK
  WAY 1, PASTE: in the tree view, right-click the screen, choose Paste, then
    Paste code (or press Ctrl+V on the screen). Copy only the lines between the
    two marker lines of one block. Studio checks the code and refuses a bad
    block with a message; that block alone is refused, the others do not
    depend on it. If Studio refuses a block, use WAY 2 for that block.
  WAY 2, BY HAND: do the steps under "BY HAND" for that block.
  Control type names (the word after "Control:") are NOT confirmed against a
  Microsoft sample: no sample was readable. So WAY 2 is the main way for every
  block. If a pasted control looks wrong, delete it and use WAY 2.
  No version is written after a type name; Studio then uses the newest.

NAMES USED (keep them, the formulas refer to them)
  btnT4a, btnRunFlow, txtProbeSearch, btnT7a, lblT7Counts, pdfT2, imgT2,
  frmProbe (the T10 form), btnT10Submit.

  1. Insert menu, Text input. Name it txtProbeSearch. Set Default to: "a"

  3. Select the OnSelect property of btnT7a, clear it, paste:
--- formula for OnSelect ---
IfError(
  ClearCollect(colProbeUsers, Office365Users.SearchUserV2({searchTerm: txtProbeSearch.Text, top: 5}).value);
  Patch('90161Z Probe', Defaults('90161Z Probe'), {Title: "RESULT", ProbeTest: "T7", ProbeWay: "a", ProbeResult: If(CountRows(colProbeUsers) > 0, "PASS", "FAIL"), ProbeDetail: "rows=" & CountRows(colProbeUsers) & " displayName=" & CountIf(colProbeUsers, !IsBlank(DisplayName)) & " department=" & CountIf(colProbeUsers, !IsBlank(Department)) & " officeLocation=" & CountIf(colProbeUsers, !IsBlank(OfficeLocation)) & " mail=" & CountIf(colProbeUsers, !IsBlank(Mail))});

  Notify("T7 a: refused (" & FirstError.Kind & ")", NotificationType.Error)
)
--- end formula ---

  5. Select the Text property of lblT7Counts, clear it, paste (counts only,
     never a name or an address):

  1. Insert menu, Edit form. Name it frmProbe.
  2. Set its DataSource property to: '90161Z Probe'
  3. Edit fields: keep only Title and Attachments.
  4. Set DefaultMode to New (the formula below).
  5. Select the Title card, set its Default property to the formula below.
  6. Select the form, set its OnSuccess property to the formula below.
  7. Insert menu, Button. Name it btnT10Submit. Set Text to: T10: submit the form
  8. Set its OnSelect to the formula below. If you named the form differently,
     use that name in place of frmProbe.
--- formula for DefaultMode ---

--- end formula ---
--- formula for Default (Title card) ---

--- end formula ---
--- formula for OnSuccess ---

--- end formula ---
